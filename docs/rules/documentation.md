# documentation.md

- Keep documentation synchronized with code changes in the same session.
- System changes → update `docs/context/architecture.md` and document with an ADR in `docs/decisions/`.
- Workspace structure changes → update `docs/context/structure.md`.
- Product/spec changes → update `docs/product/PRD.md` and matching feature spec in `docs/specs/features/`.
- Outdated docs are bugs — maintain accuracy and prune obsolete entries immediately.
