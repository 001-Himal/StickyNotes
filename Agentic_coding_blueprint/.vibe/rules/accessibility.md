# accessibility.md (Desktop UI)

- **Keyboard Navigation:** Full keyboard navigation support (Tab between header and body; Escape to cancel inline rename; Enter to commit rename).
- **Standard Shortcuts:** Support OS standard editing keys (`Ctrl+A`, `Ctrl+C`, `Ctrl+V`, `Ctrl+Z`, `Ctrl+Y`).
- **High Contrast & Legibility:** Default charcoal text on warm canary yellow (`#2B2B2B` on `#FFF8D6`) exceeds WCAG AA contrast ratio (11.5:1).
- **Clear Focus Indicators:** Subtle visual indicator when text area or inline title editor is active.
- **Dynamic Sizing:** Legible default font size (14px) with configurable scaling in settings.
