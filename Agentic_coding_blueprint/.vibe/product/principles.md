# principles.md — product thinking

1. **Digital Paper Metaphor**: The product is paper on a desk, not a computer application.
2. **Ambient, Never Distracting**: Stays on the desktop layer, vanishes beneath apps, zero unprompted notifications.
3. **Frictionless Capture**: Click anywhere on the note to type immediately; auto-saves continuously.
4. **Clean Decoupling**: Two independent executables (`Sticky Note` and `Sticky Note Settings`) sharing local JSON.
5. **Radical Resource Efficiency**: Respect the user's hardware. Idle memory <50 MB, idle CPU 0%.
