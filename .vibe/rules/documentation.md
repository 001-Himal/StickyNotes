# documentation.md

- Keep documentation synchronized with code changes in the same session.
- System changes → update `.vibe/context/architecture.md` and document with an ADR in `.vibe/decisions/`.
- Workspace structure changes → update `.vibe/context/structure.md`.
- Product/spec changes → update `.vibe/product/PRD.md` and matching feature spec in `.vibe/specs/features/`.
- Outdated docs are bugs — maintain accuracy and prune obsolete entries immediately.
